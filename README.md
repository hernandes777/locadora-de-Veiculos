
 Locadora de Veículos - Projeto Web
 Descrição:
Essa atividade foi proposta com o objetivo de desenvolver um site para uma locadora de veículos, contendo:

Tela de login

Perfil de administrador

Perfil de usuário

O principal foco foi relembrar e praticar os conceitos de Bootstrap, aplicando componentes prontos e responsivos para facilitar o desenvolvimento do layout.

 Objetivo da atividade
Praticar o uso do Bootstrap para criação de interfaces responsivas.

Revisar a estrutura de um projeto web simples.

Trabalhar com a separação de perfis de usuário e administrador.
